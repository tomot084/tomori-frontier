## 投資タイルと木材市場：強化する順番を選ぶ（2026-10-05）

ユーザーの「斧の強化や配膳係の雇用など、様々なタイルから効率を考えて投資順を選ぶ楽しさ」に対応。開始mainは `c1d2507`。公開版をブラウザで起動し `screenshots/invest-before-390.png` を保存。ローカル参考画像5枚を実画像で2回確認した。参考の固有キャラクター・雪林・ロゴ・UIは取り込んでいない。

### 問題と変更

- 従来は建築順がほぼ唯一の目的で、精霊が自動加入し、投資判断が少なかった。新規ゲームでは精霊を任意の雇用へ変更した。
- 木材が建築用に偏っていた。木5個を4灯貨で売れる市場を設け、建築か販売かを選べるようにした。建築途中の灯貨報酬と戦闘報酬も維持しているため、市場を使わない進行も可能。
- 強化の場所がメニューに隠れていた。最初の拠点に固有色・立体的な小物・現在費用を持つ地面タイル5種を配置。周囲の資源を移してタイルを隠さない。資源総数53、敵14、建築の費用は維持。

| 投資先 | 初回費用 | 効果・選択の理由 |
| --- | --- | --- |
| 道具工房 | 7灯貨 | 木を2撃から1撃へ、採集速度も上昇。手動採集を優先 |
| 背かご | 5灯貨 | 各素材容量20→30。往復を減らす |
| 運搬精霊 | 8灯貨（2体目16） | 実在資源を採集して建築へ5個ずつ運ぶ。自分は別の仕事へ |
| 灯材市場 | 6灯貨（以降12/18） | 木5個の売値4→5→6→7。販売と再投資を優先 |
| 配達係 | 6灯貨 | 木を最大30個まとめて預け、客へ自動配達。採集へ戻れる |

必須建築の順序は橋→門→灯台のまま。5種の投資は最初から並列で、市場・雇用は必須条件ではない。

市場は近づくだけでは素材を使わない。「木5を売る」または「持っている木を預ける」を押して選ぶ。配達係は実際に荷物を背負って客の待つ板張り地点へ往復し、到着時だけ売上を付与。木・灯貨のポップと粒子、客のお礼と跳ねる動作で取引を知らせる。待機中の無限収入やオフライン収入はない。

投資一覧では5種の費用、効果、向いている使い方を比較できる。「タイルへ行く」で地面の目印とHUDの方向案内を切り替え、近くの詳細画面から購入する。購入画面は時間を止める。目印を取消して開拓案内へ戻れる。既存の装備工房も継続し、戦闘・移動・HPの強化を維持した。「おすすめ」固定誘導は外した。

## 完成度改善：島が働き始める開拓ループ（2026-10-05）

ユーザーの「目指す完成度に近づけて」に対応。開始mainは `b2e2185`。既存コードと公開版の3島を実ブラウザで確認し、参考画像5枚を実画像として2回開いた。参考の雪林・キャラクター・ロゴ・固有UIは使っていない。

### 原因と優先順位

1. 人物の細かい塗り込みと、木・岩・建物の材質が揃っていない。
2. 開始画面の上部が単色の空白で、森の密度と奥行きが弱い。
3. 後半は要求数が55・90と増えるだけで、建築後の成果が遊びへ返ってこない。
4. 敵名・採集目印・建築の長いラベルが重なり、主人公や運搬が読みにくい。
5. 音がなく、採集・拾得・投入・完成の違いが視覚だけに偏っている。

### 実装

- 森と光：開始島の背景を延ばして森の木14本を配置。歩ける範囲と資源配置は維持。3島の地面・樹葉を変化させ、柔らかい環境光と弱めの影に調整。カメラを少し上からのクォータービューへ変更。
- 灯守：CC0人物の比率を少しずんぐりさせ、頭部とフードを調整。服にも同じ場面の光を当てる。元GLBの座標系反転を保持（最初の比較で反転を失った問題を修正）。骨格・道具・既存資源スタックは継続。
- 敵：目の縁とハイライトを大きくして岩や背景と区別。追跡開始距離を230→145にし、採集へ入った瞬間の多方向からの追跡を緩和。敵HPバーは維持し、名前は近い敵1体だけ表示。
- 開拓：橋の完成で灯りの精霊1体、門の完成で2体が加わる。精霊は資源地点へ歩き、実在する木・石を採集し、荷物を背負い、建築地点へ運んで投入する。プレイヤーの所持素材は使わない。プレイヤー付近の採集対象を避け、同じ対象の二重採集も防ぐ。灯実は自分で集める役割を残す。
- 門の完成で手動採集の1対象あたりの収量が+2。道具強化と合わせて後半の成長を体験できる。
- 門・灯台の25/50/75%投入時に各3灯貨を付与。完成だけでなく建築途中でも強化に進める。進捗が増えた瞬間だけ支払い、再読み込みによる重複報酬を防ぐ。
- 建築：新しい部材が短く弾んで組み上がる。完成時に、建ったものと新しく得た効果をカード表示。
- HUD：現在の一束の量を案内（容量以内）。建築名・進捗・精霊数は別行、細い進捗バーを追加。建築地点は残り必要量だけ表示し、人物から横へずらす。工房ボタンにも最初の道具の効果を表示。
- 精霊の近くの木も透過し、運搬が見えるようにする。ラベルをHUDの下へ制限。
- 音と振動：採集/打撃、回収、投入、完成、強化で短い合成音。ユーザー操作後だけAudioContextを起動。完成・強化の振動は対応環境でのみ。設定からOFFにでき、設定を端末保存。外部音源・通信・追加ダウンロードなし。

セーブはv1の既存形式・KEYを維持。建築費用、所持容量、基礎的な採集/投入判定、移動、戦闘、回復、クリア条件は維持。精霊の途中の移動・未投入の荷物は一時状態として再読み込みで野営地から再開する。プレイヤーの所持素材と投入済み建築進捗は保持される。バックグラウンド時間の採集は行わない。
