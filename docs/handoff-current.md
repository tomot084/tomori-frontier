# 前回の改善記録（保持）

2026-10-05。作業開始時のmain / GitHub Pagesは `5ec54d0`。既存リポジトリ・公開ページ・参考画像5枚を実際に確認してから変更した。

## 目的と比較

参考画像はクォータービュー、自然物の立体感、密度、採集と運搬の報酬、敵の危険表示、スマホHUDの完成度のみ参考にした。固有のロゴ、キャラクター、雪林、UI、画像素材は取り込んでいない。灯守・灯の実・草原の浮島を維持。

優先した残課題：

1. 円形地面パッチと球体の樹冠が部品の集合に見える。
2. 人物の服・足元・積み荷の輪郭が背景に埋もれる。
3. 採集・回収・投入・撃破の視覚的な成果が似ている。
4. 目標案内が抽象的で、必要な素材と方向が読めない。
5. +1ポップアップが重なり、スマホの視界を散らかす。
6. 左下だけで始めるドラッグが、右手での操作に不便。

## 実装

- 地面：大きな円形パッチを撤去。Canvasで生成した柔らかな色むらと微細な草の質感を、浮島のUVに適用。外部画像・新規通信はない。
- 木：樹冠を7つから5つのまとまった塊へ整理。林のモデル負荷も削減。岸辺の装飾木も人物の近くで透過し、採集や右手操作で岸に寄っても主役を隠さない。
- 岩：採れる月石を結晶で識別。人物：服の縁・留め具・縫い目・足元リング、待機中の斧を追加。
- 影：腕・脚・所持資源を含むキャラクターの影を表示。
- 運搬：背負った資源が歩行で揺れ、回収時に弾む。
- 採集：打撃姿勢を約50ms保持する見た目のヒットストップ。移動・シミュレーションは止めない。
- 回収：既存の吸引回収・容量・数量は維持。近づく資源を縮小し、回収イベントを追加。短い窓で回収数をまとめ、HUDを光らせる。
- 戦闘：敵の打撃反応に押しつぶしと傾き。敵名と危険色の足元リング。撃破に光の波紋。
- 建築：現地の標識、投入時のラベルとマーカーの反応、完成時の波紋と「完成！」表示。
- UI：目標の進捗率、所持・投入済み素材を差し引いた残り採集量、画面方向の建築案内。素材が揃うと投入へ案内。強化可能な工房を強調。
- UX：フィールドのHUD下で左右どちらからでもドラッグ開始。ポップアップを下部へ移し、主役の上を空ける。PCではWASD/矢印の案内。

セーブversion・コスト・採集量・敵AI・資源容量・建築開放のコアループは維持。回収イベントは所持品へ実際に入った資源にだけ発生する。
